# Source note

The base 3D-print model was purchased from [FABRI_CREATOR on Cults3D](https://cults3d.com/en/3d-model/gadget/brazo-robotico-con-arduino-step-files-robotic-arm-guardar-reproducir-export), design 1896360. The designer is not a contributor or participant in this project.

Adam Abu Toamy adapted selected printed parts, chose different electronics and servos, assembled and calibrated this build, and developed its controller and integration. Specific modifications and prototype status are listed in [README.md](README.md) / [README_AR.md](README_AR.md).

Original CAD/STL and exact mesh data are excluded from the GitHub export. The original model's distribution terms remain applicable. A license for Adam's own software has not been selected; no third-party assets are relicensed by this project.
