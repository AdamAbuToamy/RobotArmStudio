## المشروع ومساهمتي

جمّعت ذراعًا تعمل بمحركات سيرفو اعتمادًا على تصميم ميكانيكي اشتريته، وطوّرت تكامل الإلكترونيات وبرنامج Robot Arm Studio. تجميع الذراع مكتمل حسب وصف التجربة، لكن المعايرة والتحسين الميكانيكي والاختبار الفعلي مستمرة.

الكود المسترجع يتضمن التحكم بالمفاصل والمقبض والسرعة، وحفظ الوضعيات والحركات وتشغيلها، وواجهة عربية وإنجليزية، وخيار التحكم من الهاتف عبر الكمبيوتر المحلي. وجود هذه الخصائص في البرنامج لا يعني التحقق من كل حركة على العتاد.

### محاكي XYZ وتخطيط المسار

يحتوي الموقع على محاكي تفاعلي لاختيار نقطة هدف داخل مساحة XYZ ومعاينة وضعية وصول الذراع إليها. تحسب الحركيات العكسية (IK) وضعية المفاصل، ويستخدم مخطّط المسار خوارزمية A* ضمن خريطة مسارات PRM عند الحاجة إلى مسار غير مباشر. بدأ العمل على كاميرا ESP32-CAM وقواعد تثبيتها، وهي قيد التجربة.

تنفيذ المسار على الذراع الفعلية يحتاج الاتصال والمعايرة؛ المشروع ما زال قيد التطوير.

تُحدّث قائمة القطع بالتتابع وفق التفاصيل التي يقدّمها صاحب المشروع.

## التشغيل

على Windows شغّل `START_WINDOWS.bat`. على Linux/macOS:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

يربط الكمبيوتر المتصفح باللوحة عبر USB. خيار الهاتف يستخدم الكمبيوتر نفسه عبر الشبكة المحلية. اقرأ [إعداد الأجهزة](docs/HARDWARE.md) قبل تحريك الذراع.

## الاختبارات وحدود النتيجة

اجتازت اختبارات الخادم الثمانية أثناء تجهيز المستودع باستخدام محاكاة اتصال العتاد. ليست اختبارًا للروبوت الفعلي. لا يوجد قياس مباشر لزوايا المفاصل أو قوة الإمساك، ولا يُدّعى اكتمال الالتقاط الذاتي أو تحقيق دقة ملليمترية مثبتة.
