## المشروع ومساهمتي

جمّعت ذراعًا تعمل بمحركات سيرفو اعتمادًا على تصميم ميكانيكي اشتريته، وطوّرت تكامل الإلكترونيات وبرنامج Robot Arm Studio. تجميع الذراع مكتمل حسب وصف التجربة، لكن المعايرة والتحسين الميكانيكي والاختبار الفعلي مستمرة.

الكود المسترجع يتضمن التحكم بالمفاصل والمقبض والسرعة، وحفظ الوضعيات والحركات وتشغيلها، وواجهة عربية وإنجليزية، وخيار التحكم من الهاتف عبر الكمبيوتر المحلي. وجود هذه الخصائص في البرنامج لا يعني التحقق من كل حركة على العتاد.

## القطع

| القطعة | المعلومات الموثقة |
| --- | --- |
| المتحكم | ESP32-S3 |
| مشغّل السيرفو | PCA9685؛ البرنامج يتعامل مع ست قنوات |
| محرك القاعدة | سيرفو من فئة 20 kg·cm |
| محرك المرفق | MG995 |
| الرسغ والدوران والمقبض | MG90S في التجميع الموصوف |
| تغذية السيرفو | 5V / 10A وفق توثيق الكود المسترجع |
| الهيكل | قطع مطبوعة ثلاثيًا مبنية على تصميم مشترى |
| ESP32-CAM وVL53L0X | قطع موجودة؛ دمجها مخطط له وليس مكتملًا |

موديل محرك الكتف الحالي غير محسوم. التفاصيل في [سجل القطع](docs/COMPONENTS.md). قيم نبضات السيرفو أوامر تحكم وليست قراءات حساسات.

## الصعوبات والعمل الجاري

| الصعوبة التي واجهتها | العمل الموثق / ما بقي |
| --- | --- |
| حدود المحركات واتجاهاتها | معايرة ومطابقة الواجهة مع الحركة الفعلية؛ التحسين مستمر |
| الحركة المفاجئة | التحكم بالسرعة وتنعيم الحركة موجودان في الكود؛ الضبط الفعلي مستمر |
| اهتزاز MG90S وضعف المقبض | ظهرا خلال التجارب؛ لا يُدّعى حل نهائي أو قياس لقوة الإمساك |
| الاحتكاك وملاءمة الأجزاء المطبوعة | تحسين ميكانيكي مستمر |
| استمرار الإمساك مقابل تحرير نبضات السيرفو | سلوك الإمساك والتحرير موجود؛ المؤقت ليس حساسًا لاكتشاف التعثر |

## مراحل التطوير

| المرحلة | الحالة |
| --- | --- |
| طباعة وتجميع الذراع | أُبلغ عن اكتمال التجميع؛ تحسين الملاءمة والثبات مستمر |
| توصيل الإلكترونيات والتحكم اليدوي | منفذ، ويظهر في التسجيل الأصلي |
| المعايرة وحفظ الحركات والتحكم من الهاتف | موجودة في البرنامج المسترجع؛ اختبار التكامل مستمر |
| تحسين السلاسة والقبضة وتكرار الحركة | قيد العمل؛ لا توجد دقة تكرار مقاسة يُدّعى تحقيقها |
| دمج الكاميرا وحساس المسافة والالتقاط بالرؤية | مخطط له وغير مكتمل |

## التشغيل

على Windows شغّل `START_WINDOWS.bat`. على Linux/macOS:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

يربط الكمبيوتر المتصفح باللوحة عبر USB. خيار الهاتف يستخدم الكمبيوتر نفسه عبر الشبكة المحلية. اقرأ [إعداد الأجهزة](docs/HARDWARE.md) قبل تحريك الذراع.

## الاختبارات وحدود النتيجة

اجتازت اختبارات الخادم الثمانية أثناء تجهيز المستودع باستخدام محاكاة اتصال العتاد. ليست اختبارًا للروبوت الفعلي. لا يوجد قياس مباشر لزوايا المفاصل أو قوة الإمساك، ولا يُدّعى اكتمال الالتقاط الذاتي أو تحقيق دقة ملليمترية مثبتة.
